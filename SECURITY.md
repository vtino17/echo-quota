# Security policy

Please report vulnerabilities through GitHub private vulnerability reporting instead of a public issue.

Include the affected command or component, a minimal reproduction, impact, and any suggested mitigation. Do not include private corpus content in a report. Maintainers will acknowledge a valid report as soon as practical.

EchoQuota evaluates metadata supplied by the caller. See the [threat model](docs/THREAT-MODEL.md) before using a receipt as a security boundary.
